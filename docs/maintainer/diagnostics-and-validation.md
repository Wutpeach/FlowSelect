# Diagnostics & Validation

Maintainer runbook for Ameow's runtime diagnostics, capability probes, telemetry, and smoke validation.

## Startup Diagnostics

Enable startup window diagnostics with the `AMEOW_STARTUP_DIAGNOSTICS` environment variable:

```bash
AMEOW_STARTUP_DIAGNOSTICS=true npm run dev
```

When enabled, the app captures:

- Window startup screenshots at key phases (PNG files)
- Pixel transparency analysis of the captured screenshots
- Window state metadata (bounds, visibility, minimized, focused, alwaysOnTop, destroyed)

Output is written to `startup-diagnostics-latest.txt` plus per-capture PNG files in the app's log directory.

Source: `electron/startupDiagnostics.mts`, `electron/windowVisibility.mts`.

## Support Log Export

Support logs are exported via an IPC command (`supportLogCommands`), accessible from the desktop app's support/diagnostics UI. The exported file `support-<timestamp>.txt` contains:

| Section | Content |
| --- | --- |
| `[environment]` | appVersion, platform, arch, configPath, logDir, runtimeLogPath |
| `[settings]` | Current configuration (JSON) |
| `[runtime]` | Runtime dependency status (JSON) |
| `[recent-runtime-log]` | Recent runtime log lines |

Source: `electron/supportLogExport.mts`.

## Capability Probes

Capability probes test yt-dlp and gallery-dl downloader capabilities against known URLs.

### Commands

```bash
npm run capabilities:seed           # Generate the capabilities seed file
npm run capabilities:probe           # Run probes against targets (default 45s timeout)
npm run capabilities:probe:review    # Generate a review report from probe results
```

### CLI Options (probe)

| Option | Default | Purpose |
| --- | --- | --- |
| `--targets <path>` | `src/assets/capabilities-probe-targets.json` | Probe target definitions |
| `--output <path>` | `src/assets/capabilities-probe.json` | Output path for probe results |
| `--timeout <ms>` | `45000` (45s) | Per-probe timeout |

### Artifacts

| File | Purpose |
| --- | --- |
| `src/assets/capabilities-probe-targets.json` | Target URLs to probe |
| `src/assets/capabilities-seed.json` | Seed data (~35k lines, generated by `capabilities:seed`) |
| `src/assets/capabilities-probe.json` | Probe results |

Source: `scripts/run-capability-probes.ts`, `scripts/generate-capabilities-seed.mjs`, `src/download-capabilities/probe.js`.

## Telemetry Report

```bash
npm run telemetry:report
```

Generates a download telemetry report. The schema is documented in `docs/download-telemetry-schema.md`.

Source: `scripts/generate-download-telemetry-report.ts`.

## Runtime Smoke Validation

Smoke tests validate the bundled Python runtime and downloader capabilities.

```bash
npm run runtime:smoke:python           # Smoke-test the bundled Python runtime
npm run runtime:smoke:downloaders       # Smoke-test managed Python downloaders (builds Electron first)
npm run runtime:verify:macos-package    # Verify macOS Python runtime package
```

### macOS Runtime Package Verification (CI)

`.github/workflows/verify-macos-runtime-package.yml` can be triggered manually (`workflow_dispatch`):

- Runner: macos-15, arm64
- Runs `npm run runtime:verify:macos-package` with flags:
  - `require-execution`
  - `require-downloader-bootstrap`
  - `require-relocation-rebuild`
- Outputs verification JSON

Source: `scripts/smoke-python-runtime.mjs`, `scripts/smoke-managed-python-downloaders.mjs`, `scripts/verify-macos-python-runtime-package.mjs`.
