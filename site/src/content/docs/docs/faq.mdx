## 我应该下载哪个文件？

普通 Windows 用户优先下载 Installer EXE；临时试用或放进工具目录时下载 Portable ZIP。M 系列 Mac 用户下载 macOS Apple Silicon / arm64 DMG。

浏览器扩展单独下载 `browser_extension.zip`，它不是桌面应用本体。不要下载 `Source code.zip` 或 `Source code.tar.gz`，那是源码，不是可直接运行的应用。

继续深入：阅读 [下载 Ameow](../downloads/)。

## macOS 首次启动被系统拦截怎么办？

先按这个顺序处理：

1. 确认已经把 `Ameow.app` 拖到 `Applications`。
2. 在 `Applications` 中右键 `Ameow.app`，选择“打开”。
3. 如果仍被拦截，打开 `系统设置 > 隐私与安全性`，找到 Ameow 的拦截提示并允许打开。
4. 如果仍失败，再使用 quarantine 命令：

```bash
xattr -dr com.apple.quarantine "/Applications/Ameow.app"
```

继续深入：阅读 [macOS 首次启动](../troubleshooting/macos-first-run/)。

## 拖入文件后，文件去了哪里？

先从 Ameow 打开“当前输出目录”。不要只凭记忆去找默认目录。

默认输出目录通常是：

```text
Desktop/Ameow_Received
```

但如果你曾经把文件夹拖进 Ameow，当前输出目录会切换成那个文件夹。

继续深入：阅读 [输出目录](../desktop/output-folder/) 和 [找不到文件](../troubleshooting/missing-files/)。

## 拖入文件夹为什么没有复制整个文件夹？

拖入文件和拖入文件夹的含义不同：

- 拖入文件：移动文件到当前输出目录。
- 拖入文件夹：把该文件夹设为新的输出目录。

这样设计是为了让你快速指定后续素材保存的位置。如果你想收集某个文件夹里的文件，请打开文件夹后选择里面的文件再拖入。

## 粘贴链接后没有开始下载怎么办？

先按这 4 步判断：

1. 链接能否在浏览器中正常打开。
2. 先换成公开页面或公开媒体链接测试。
3. 当前输出目录是否可写。
4. 这个站点和页面类型是否在当前支持范围内。

如果内容需要登录、会员、地区权限、年龄验证或 Cookies，优先安装浏览器扩展并从具体内容页发送任务。

继续深入：阅读 [快速上手](../getting-started/) 和 [下载失败](../troubleshooting/download-failures/)。

## 浏览器扩展显示 Disconnected 怎么办？

先启动 Ameow 桌面端，再打开扩展弹窗。扩展依赖本地连接，桌面端没有运行时一定会显示未连接。

如果桌面端已经运行：

1. 关闭并重新打开扩展弹窗。
2. 在浏览器扩展管理页重新加载 Ameow 扩展。
3. 重启 Ameow 桌面端。
4. 检查防火墙或安全软件是否拦截本地连接 `127.0.0.1:39527`。

继续深入：阅读 [扩展未连接](../troubleshooting/extension-disconnected/)。

## 当前支持哪些站点？

当前公开文档列出的重点站点包括 YouTube、Bilibili、X / Twitter、Douyin、Xiaohongshu、Weibo。站点支持会随版本演进；同一个站点里的会员内容、私密内容、地区限制内容也可能失败。

判断站点前，先确认你在具体内容页上测试，而不是首页、搜索结果、推荐流、作者主页或合集页。很多站点的问题不是“完全不支持”，而是当前页面里混着多个预览资源和旁路内容。

继续深入：阅读 [支持站点](../extension/supported-sites/)。

## YouTube 在浏览器里能播，但 Ameow 还是失败怎么办？

先别急着改 Ameow 设置，优先排查代理环境。

这类情况很常见于：

- 浏览器走了代理，但 Ameow 没有走到同一条网络路径。
- 代理软件只代理了浏览器，没接管本地下载器链路。
- 你正在首页、搜索页或推荐流里测试，而不是具体视频页。

推荐顺序：

1. 打开具体 YouTube 视频页确认能正常播放。
2. 通过扩展从当前视频页发送任务。
3. 让代理工具使用 TUN / 全局 / VPN / 系统代理接管模式后再试。
4. 先用公开视频和均衡质量验证。

当前产品方向是让用户自己的代理工具接管网络。Ameow 也内置了网络代理设置，可以在"系统与支持 → 网络代理"中选择系统代理或手动代理模式。详见 [常用设置](../desktop/settings/)。

## 什么时候需要浏览器扩展？

只拖拽本地文件、整理文件夹或粘贴普通公开链接时，可以先不装扩展。

需要扩展的典型情况：

- 网页视频需要登录态或 Cookies。
- 页面内有专用下载入口。
- 你希望从当前内容页直接发送到桌面端。
- 你想从扩展弹窗里的“当前页面资源”选择视频、音频或图片。
- 你希望同步下载质量偏好。

如果你打算使用“当前页面资源”，先进入具体视频页、帖子页、作品页或详情页；不要在首页、搜索页、推荐流或列表页上期待它自动只命中你眼前那一个资源。

继续深入：阅读 [浏览器扩展](../browser-extension/)。
