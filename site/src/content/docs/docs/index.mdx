Ameow 是一个常驻桌面的悬浮下载与收集窗口。你把文件、文件夹或网页链接交给悬浮窗口，Ameow 按当前设置把结果保存到输出目录。配合浏览器扩展，网页里的视频和资源也能直接发到桌面处理。

核心模型只有一条线：**把内容交给 Ameow → Ameow 处理任务 → 结果进入当前输出目录。**

## 桌面端和浏览器扩展是什么关系？

桌面端可以独立工作。你只需要悬浮窗口就能拖文件、粘贴链接和下载公开内容。

浏览器扩展是可选增强，适合这些场景：

- 网页能播放但复制链接后 Ameow 失败。
- 内容需要登录态、Cookies 或会员权限。
- 你想从当前页面里直接选择视频、音频或图片资源。

扩展需要连接正在运行的桌面端才能发送任务。不需要扩展时，先不安装。
