title: 悬浮窗口

悬浮窗口是 Ameow 的主入口。它常驻桌面边缘，用来接收你正在整理的文件、文件夹和网页链接。你不需要先打开完整管理界面，只要把内容交给这个小窗口即可。

先用它完成两个动作：拖一个文件进去，再打开当前输出目录确认文件出现。这个闭环跑通后，再处理网页链接和扩展任务会更容易判断问题。

[截图：Ameow 悬浮窗口停靠在桌面边缘，显示可拖入文件和粘贴链接的状态]

## 你可以交给它什么？

| 内容 | 操作 | 结果 |
| --- | --- | --- |
| 本地文件 | 拖进悬浮窗口 | 文件移动到当前输出目录 |
| 本地文件夹 | 拖进悬浮窗口 | 该文件夹变成新的输出目录 |
| 网页链接 | 复制后粘贴到窗口 | Ameow 尝试创建下载任务 |
| Windows 剪贴板文件 | 在资源管理器复制后粘贴 | 文件复制到当前输出目录 |

成功状态取决于内容类型：文件会出现在输出目录，链接会进入队列，文件夹会切换输出目录。

## 常用动作

### 拖入文件

1. 在资源管理器、Finder 或桌面选中文件。
2. 拖到 Ameow 悬浮窗口。
3. 松开鼠标。
4. 打开当前输出目录，确认文件出现。

### 粘贴链接

1. 在浏览器复制链接。
2. 让 Ameow 窗口可接收输入。
3. 按 `Ctrl+V`；macOS 使用 `Cmd+V`。
4. 查看是否出现任务状态。

如果窗口当前是 compact 图标状态，下载任务开始时会先展开成完整面板，再显示进度或结果状态。

### 打开输出目录

双击窗口空白区域，或右键窗口打开当前输出目录。这个动作适合在下载完成后快速找到文件。

## 窗口位置和使用习惯

你可以把悬浮窗口拖到桌面边缘或自己顺手的位置。建议放在不遮挡主要工作区的位置，例如屏幕右侧或角落。它的目标是随时接收内容，而不是占据注意力。

如果窗口短暂消失、位置不合适或快捷键唤起不符合预期，先尝试拖回目标位置，再检查常用设置中的快捷键和启动行为。不要把窗口位置问题和下载失败混在一起排查。

## 常见误解

- 拖入文件夹不是复制整个文件夹，而是切换输出目录。
- 粘贴链接不保证所有网站都能下载，站点支持和登录态会影响结果。
- 找不到文件时，先打开当前输出目录，不要只看默认目录。
