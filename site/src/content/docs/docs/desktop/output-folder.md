---
title: 输出目录
description: 理解 Ameow 当前输出目录、默认位置、切换方式和找不到文件时的定位方法。
---

输出目录是 Ameow 保存结果的位置。本地文件移动、链接下载、浏览器扩展发送的任务，都会进入当前输出目录。

找文件时先从 Ameow 打开当前输出目录，不要先猜默认路径。只要你拖入过文件夹，当前目录就可能已经变了。

[截图：通过双击或右键从 Ameow 打开当前输出目录]

## 默认位置

如果你没有改过目录，默认输出目录通常是：

```text
Desktop/Ameow_Received
```

第一次使用时，你可以先到桌面查看 `Ameow_Received` 文件夹。但日常使用时，更可靠的方法是从 Ameow 里打开当前输出目录。

## 打开当前输出目录

常用方式：

1. 双击 Ameow 悬浮窗口空白区域。
2. 或右键悬浮窗口，选择打开当前输出目录。
3. 在打开的文件夹里按修改时间排序，查看最新文件。

成功状态：系统文件管理器打开当前保存位置，你能看到刚刚移动或下载的文件。

## 切换输出目录

有三种常见方式：

- 把一个文件夹拖进悬浮窗口。
- 右键悬浮窗口，重新选择目录。
- 在设置页中调整目录。

切换后，后续文件和下载结果会进入新目录。已经保存过的旧文件不会自动移动。

## 文件夹拖入的特殊含义

拖入文件夹时，Ameow 把它理解为“以后保存到这里”。这和拖入文件不同：

- 拖入文件：移动文件。
- 拖入文件夹：切换输出目录。

如果你只是想收集文件夹里的某些文件，请先打开文件夹，选择里面的文件再拖入。

## 找不到文件时

按顺序排查：

1. 从 Ameow 打开当前输出目录。
2. 回想你是否刚刚拖入过一个文件夹。
3. 检查任务是否仍在下载中或转换中。
4. 按修改时间排序。
5. 如果开启了重命名规则，搜索最近生成的文件，而不是只搜索原网页标题。

如果任务显示完成但目录里仍找不到，继续看 [找不到文件](../../troubleshooting/missing-files/)。
