Ameow is a desktop floating window for downloading and collecting. You hand files, folders, or web links to the floating window, and Ameow saves the results to the current output folder. With the browser extension, web videos and resources can also be sent straight to the desktop.

The core model is one line: **give content to Ameow → Ameow processes the task → results land in the current output folder.**

## How Do the Desktop App and Browser Extension Relate?

The desktop app works on its own. You only need the floating window to drop files, paste links, and download public content.

The browser extension is an optional enhancement for these scenarios:

- A web page plays in the browser, but pasting the link into Ameow fails.
- Content needs login state, cookies, or membership access.
- You want to pick video, audio, or image resources directly from the current page.

The extension must connect to a running desktop app to send tasks. If you don't need the extension, don't install it yet.
