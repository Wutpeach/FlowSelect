---
title: Output Folder
description: Understand Ameow's current output folder, default location, how to change it, and how to find files later.
---

The output folder is where Ameow saves results. Local-file moves, pasted-link downloads, and tasks sent from the browser extension all land in the current output folder.

When you cannot find a file, open the current output folder from Ameow first instead of guessing the default path. If you have dropped a folder before, the current folder may already be different.

[Screenshot: opening the current output folder from Ameow by double-click or right-click]

## Default location

If you have never changed it, the default output folder is usually:

```text
Desktop/Ameow_Received
```

That is a good place to check on first use. For daily work, opening the current output folder from Ameow is more reliable than assuming the default path still applies.

## Open the current output folder

Common ways:

1. Double-click an empty area of the Ameow floating window.
2. Or right-click the floating window and choose the option to open the current output folder.
3. In the file manager, sort by modified time and inspect the newest files.

Success state: your file manager opens the current save location and shows the latest moved or downloaded files.

## Change the output folder

Three common ways:

- drop a folder onto the floating window;
- right-click the floating window and choose another folder;
- adjust it in the settings page.

After the switch, future files and downloads go to the new folder. Already saved files do not move automatically.

## The special meaning of dropping a folder

When you drop a folder into Ameow, the app reads that as "save future files here." That is different from dropping a file:

- drop a file: move the file;
- drop a folder: change the output folder.

If you only want files inside a folder, open the folder and drop the files instead.

## When you cannot find a file

Check in this order:

1. Open the current output folder from Ameow.
2. Ask whether you recently dropped a folder into the app.
3. Check whether the task is still downloading or converting.
4. Sort by modified time.
5. If rename rules are enabled, search for recently generated files instead of only the original page title.

If a task shows done but the file is still missing, continue to [Missing Files](../../troubleshooting/missing-files/).
